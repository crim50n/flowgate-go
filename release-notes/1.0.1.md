# Flowgate 1.0.1

## Fixes

- Restore the original Flowgate Smart DNS model by using Blocky `customDNS.mapping` instead of denylist sinkhole responses.
- Smart DNS A queries now return the Flowgate IPv4 address, while AAAA, HTTPS, SVCB, and other unmapped query types return NOERROR with an empty Answer.
- Keep the generic Angie TLS passthrough listener before reverse-proxy service listeners so unmatched service SNI cannot become the fallback route.
- Avoid unnecessary Blocky restarts when changes affect only Angie, including repeated `flowgate service` commands.
- Track the active Blocky TLS certificate and key so ACME renewal still triggers exactly one required Blocky restart.

GeoSite `domain` and `full` entries follow Flowgate's suffix-domain Smart DNS semantics. Blocky cannot express DLC `regexp`/`keyword` rules through `customDNS`; Flowgate reports those rules as skipped for DNS interception while retaining them in Angie SNI matching.
