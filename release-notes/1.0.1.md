# Flowgate 1.0.1

## Fixes

- Avoid unnecessary Blocky restarts when changes affect only Angie, including repeated `flowgate service` commands.
- Keep Blocky running when its generated configuration and domain list are unchanged.
- Do not restart Blocky during rollback when the failed transaction never touched the Blocky runtime.
- Track the active Blocky TLS certificate and key so ACME renewal still triggers exactly one required Blocky restart.

This prevents rapid reverse-proxy service updates from exhausting systemd restart limits while preserving DNS, DoH, DoT, and certificate renewal behavior.
