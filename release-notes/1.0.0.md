# Flowgate 1.0.0

Initial Go release of Flowgate.

## Highlights

- Smart DNS interception with Blocky and TLS/SNI passthrough with Angie.
- HTTPS reverse proxy services with Angie ACME certificate management.
- GeoSite selectors backed by an external, checksum-verified `dlc.dat` database.
- Explicit `flowgate update` support for Domain List Community updates.
- DNS hostname setup for Blocky DoH and DoT endpoints.
- Transactional configuration validation, application, rollback, and retained backups.
- Inter-process locking and atomic file replacement for concurrent CLI safety.
- Static Linux amd64 and arm64 release binaries and an Angie + Blocky Docker runtime.

## Reliability and security

- Isolated Angie candidate validation without modifying production configuration files.
- Checksum verification for downloaded runtime assets.
- Pinned Go, Angie, Blocky, UPX, base images, and GitHub Actions used by the release pipeline.
- `go test -race`, `go vet`, `staticcheck`, `govulncheck`, and Docker integration release gates.
