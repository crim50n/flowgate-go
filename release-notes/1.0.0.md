# Flowgate 1.0.0

Initial Go release of Flowgate.

## Highlights

- Smart DNS with Blocky `customDNS.mapping`: matching A queries return the Flowgate IPv4 address, while AAAA, HTTPS, SVCB, and other unmapped record types return NOERROR with an empty Answer.
- Transparent TLS/SNI passthrough with Angie; reverse-proxy services are routed separately and cannot become the fallback for Smart DNS traffic.
- HTTPS reverse proxy services with Angie ACME certificate management.
- GeoSite selectors backed by an external, checksum-verified `dlc.dat` database.
- GeoSite `domain` and `full` entries use Flowgate suffix-domain semantics; DLC `regexp` and `keyword` rules remain available to Angie SNI matching but are not representable in Blocky `customDNS`.
- Explicit `flowgate update` support for Domain List Community updates.
- DNS hostname setup for Blocky DoH and DoT endpoints.
- Blocky restarts only when its effective configuration or TLS certificate changes; reverse-proxy-only updates do not restart DNS.
- Transactional configuration validation, application, rollback, retained backups, inter-process locking, and atomic file replacement.
- Static Linux amd64 and arm64 release binaries and an Angie + Blocky Docker runtime.

## Reliability and security

- Isolated Angie candidate validation without modifying production configuration files.
- SHA-256 verification for downloaded runtime assets and DLC updates.
- Pinned Go, Angie, Blocky, UPX, base images, and GitHub Actions used by the release pipeline.
- `go test -race`, `go vet`, `staticcheck`, `govulncheck`, and Docker integration release gates.
- Integration coverage for Smart DNS A/NODATA semantics, DoT, `category-ai-!cn`, TLS passthrough, concurrent CLI operations, rollback, and certificate renewal.
